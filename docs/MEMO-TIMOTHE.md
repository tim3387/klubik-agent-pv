# Mémo : créer un réel avec Claude

## Les phrases qui marchent

| Tu veux… | Tu écris |
|---|---|
| Refaire un réel vu ailleurs | « Refais ce réel : <lien> » |
| Partir d'une idée | « Fais un réel de 20 s sur <sujet>, style <clair / sombre / site-club> » |
| Changer un texte | « Scène 2 : remplace “…” par “…” » |
| Changer le rythme | « Le compteur monte trop vite », « Garde la scène 4 une seconde de plus » |
| Montrer ce que tu veux | Envoie une capture d'écran et dis ce qui ne va pas |
| Changer un visuel | « Dans le téléphone, mets l'affiche jour de match de Saint-Étienne » |
| Une image premium | « Génère le maillot JA Isle en photo studio » |
| Ajouter ta voix | « Ma voix est dans le Drive : Voix/<nom du fichier>. Cale les animations dessus et ajoute les sous-titres. » |
| Ajouter une musique | « Mets la musique Musiques/<nom> sous la vidéo » |
| Le script de ta voix | « Écris-moi le script voix off de ce réel » |
| Publier | « Programme ce réel sur Instagram et TikTok jeudi à 18 h avec cette légende : … » |
| Qu'il retienne | « Ajoute à la méthode : je préfère … » |

## Le déroulé d'un réel
1. **Lien ou idée** : tu le donnes.
2. **Tableau** : Claude te propose les textes, scène par scène. **Corrige ici.**
3. **Vidéo** : 2 à 5 minutes plus tard, le MP4 arrive dans la conversation.
4. **Retouches** : une phrase par changement.
5. **Voix, musique** si tu veux.
6. **Publication.**

## Les règles
- Aucun faux chiffre à l'écran : donne tes vrais chiffres.
- Vérifie toujours les images générées de tes produits clients.
- Ne colle jamais une clé ou un mot de passe dans la conversation.
- Budget Higgsfield : 0,25 crédit par image premium. Claude te demande avant de dépasser 2 crédits par réel.
